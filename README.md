Entry for [One Star, Five Stars for the Food](https://make.fun/c/u-po-pu-one-star-five-stars-for-the-food-f9166ee7) on Make.fun.

One star for the planet, five stars for the food: a one-sentence review
where a $3 taco from a truck at 2am is good enough to extend a visa by a
year. `main.ts` writes the entry to `/output/entry.txt` (set `OUTPUT_DIR`
to override the output folder for local testing). Runs offline, no network.

## Run

```sh
node main.ts
```
